# Music Visualizer

This project is a real-time music visualizer that uses shaders to create dynamic graphical effects based on audio input.

## Features
*   Real-time audio processing and visualization.
*   Customizable visuals through GLSL shaders.
*   Support for multi-pass shader effects.
*   Automatic shader reloading for live editing.
